# Adaptive Lattice Gauge Solvers for Stiff Field Theories

Adaptive lattice routines for stiff gauge-field simulations.

## Availability

The implementation is publicly available under the MIT license.

Install with `pip install -e .` and run `python experiments/run_baseline.py --config configs/default.yaml`.

## Citation

This repository accompanies the paper *Adaptive Lattice Gauge Solvers for Stiff Field Theories* (ICPS 2026).
