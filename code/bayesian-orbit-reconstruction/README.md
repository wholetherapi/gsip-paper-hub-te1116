# Bayesian Reconstruction of Chaotic Orbital Trajectories

Bayesian inference utilities for chaotic orbital reconstruction.

## Availability

The implementation is publicly available under the MIT license.

Install with `pip install -e .` and run `python experiments/run_baseline.py --config configs/default.yaml`.

## Citation

This repository accompanies the paper *Bayesian Reconstruction of Chaotic Orbital Trajectories* (ICPS 2026).
