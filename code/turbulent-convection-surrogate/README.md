# Operator-Learning Surrogates for Turbulent Convection

Operator-learning surrogates for turbulent convection experiments.

## Availability

The implementation is publicly available under the MIT license.

Install with `pip install -e .` and run `python experiments/run_baseline.py --config configs/default.yaml`.

## Citation

This repository accompanies the paper *Operator-Learning Surrogates for Turbulent Convection* (ICPS 2026).
